## 🚀 Featured project

### [Tire Inspection Digitalization](https://github.com/juanerv1/digitalizacion-inspecciones)

An offline-first system that replaced **paper-based tire inspections** of agro-industrial equipment and the manual re-entry of that data. I built it end to end for an agro-industrial company, including the time spent in the field with the inspectors to understand how they really work.

[![Watch the demo](https://img.youtube.com/vi/WKXFmAAf3YM/maxresdefault.jpg)](https://youtu.be/WKXFmAAf3YM)

| | |
|---|---|
| 📱 **Mobile app** | Flutter app with local SQLite storage. Inspectors record data tire by tire with no connection and sync later. |
| ⚙️ **REST API** | FastAPI + SQLAlchemy + Alembic + PostgreSQL. Bulk CSV import with Pandas, Excel reports, and separate authentication for web (JWT) and mobile (API key). |
| 🖥️ **Admin web** | React + TypeScript platform to manage clients, load data and review inspections. |
| 🔄 **Sync** | Asynchronous and idempotent, with integrity checks and a full rollback when data is inconsistent. |
| 🧪 **Quality** | 134 automated tests (pytest and flutter_test) and a GitHub Actions pipeline that runs tests, static analysis and builds on every push. |
| 🐳 **Run it** | The whole backend stack starts with `docker compose up`. The Android APK is in the releases. |

**Stack:** `Python` `FastAPI` `PostgreSQL` `Flutter` `React` `TypeScript` `Docker` `GitHub Actions`

👉 **[See the repository](https://github.com/juanerv1/digitalizacion-inspecciones)** for the architecture, the test strategy and a step-by-step guide to try it yourself.
